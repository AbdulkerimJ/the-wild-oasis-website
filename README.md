# The Wild Oasis Website

Welcome to **The Wild Oasis**, a luxurious cabin booking platform. The website allows users to explore cozy luxury cabins nestled in the heart of the Italian Dolomites, filter them by capacity, and easily make reservations for a peaceful vacation.

## 🚀 Tech Stack

This project is built with modern web technologies:

- **Framework:** [Next.js](https://nextjs.org/) (App Router, Version 16+)
- **Library:** [React 19](https://react.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Backend & Database:** [Supabase](https://supabase.com/)
- **Authentication:** [NextAuth.js](https://next-auth.js.org/)
- **Icons:** [Heroicons](https://heroicons.com/)

## ✨ Key Features

- **Explore Cabins:** Browse through beautiful, detailed listings of luxury cabins.
- **Filtering:** Quickly filter available cabins based on guest capacity.
- **Reservations:** A seamless booking experience for users.
- **User Authentication:** Secure login and user account management using NextAuth and Supabase.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.

## 🛠️ Getting Started

First, ensure you have the required environment variables set up in your `.env.local` file (e.g., Supabase URL, API keys, NextAuth secret).

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

- `app/`: Next.js App Router containing pages for home, cabins, about, login, and user account.
- `app/_components/`: Reusable UI components like Navigation, Filters, and Spinners.
- `app/_lib/`: Utility functions and types.
- `public/`: Static assets (images, icons).
